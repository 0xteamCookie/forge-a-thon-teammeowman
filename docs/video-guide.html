Anvil demo video: setup and recording, step by step

You will record one screen video, at most 4 minutes, showing Tasks A, B and C in that order, each followed by a terminal command that proves it worked. Setup takes about 20 minutes once. Read the rules box before you record.

Rules from the problem statement (breaking one costs marks):
  • Order is A, then B, then C. Each must be followed by its check on screen. Max 4:00.
  • You may cut time spent waiting for the model. Never cut between giving an instruction and the diff appearing.
  • During Task B, briefly show the TrueForge session (the "Session" button).
  • The API key must never appear on screen.

Part 1. One-time setup (about 20 minutes)

1.1 Check you have these

  • Linux or macOS (Windows: use WSL). git, VS Code, Python 3.10 or newer, OBS Studio.
  • Node 22.14 or newer: run node -v. If it is lower, install nvm and run nvm install 22 then nvm use 22.
  • Your own Anthropic API key (starts with sk-ant-, from console.anthropic.com). Each take costs well under $1. Keep it off screen.

1.2 Download everything (copy and paste, one block)

mkdir forgeathon && cd forgeathon
git clone https://github.com/0xteamCookie/forge-a-thon-teammeowman anvil
git clone --branch 3.1.3 https://github.com/pallets/flask flask-3.1.3
cd flask-3.1.3
python3 -m venv .venv
.venv/bin/pip install -e . "pytest==8.4.2" asgiref python-dotenv
cd ../anvil/extension
npm install
npm run build
cd ../..

The two folders anvil and flask-3.1.3 must sit next to each other inside forgeathon. pytest must be exactly 8.4.2.

Part 2. Before every recording session

  1. Terminal 1: start TrueForge and leave it open the whole time: 
    cd forgeathon
./anvil/scripts/start-trueforge.sh
    Wait until it prints Agent server listening on http://localhost:8790.
  2. Terminal 2: set the key and reset everything (this terminal is never recorded): 
    cd forgeathon
export ANTHROPIC_API_KEY=sk-ant-...
./anvil/scripts/demo-reset.sh
    You should see git status: '' (empty = clean) and two ok lines. It also prints every instruction and command you will paste in the video. Keep that terminal visible on a second screen, or copy the lines into a note.
  3. In Terminal 2: code anvil. In that VS Code window press F5. A second window opens with the Flask project: record only this second window.
  4. In the second window, check the bottom-right status bar reads Anvil · anthropic/claude-sonnet-5-5 (+1 fallback). Click the anvil icon in the left activity bar: the Anvil panel should show Connected to TrueForge.
  5. Open a terminal inside that window: menu Terminal → New Terminal. It opens in the Flask folder. Drag the panel up so the terminal is about a third of the screen. Close all open editor tabs.
  6. Practice once without recording (Part 4), then run ./anvil/scripts/demo-reset.sh in Terminal 2 again and close any open tabs before the real take.

Part 3. OBS settings (once)

  1. Settings → Video: Base and Output resolution 1920x1080, 30 FPS. Settings → Output: Recording format mp4.
  2. Sources → + → Screen Capture (Linux: "Screen Capture (XSHM)" or "PipeWire"; Mac: "macOS Screen Capture"). Pick the screen where the second VS Code window is, maximised.
  3. Mute Desktop Audio and Mic unless you want to narrate (narration is optional).
  4. Turn on Do Not Disturb and close chat apps so no notification shows up in the video.

Part 4. Recording, step by step

Press Start Recording in OBS, then follow exactly. Times are a target; the hard limit is 4:00 total.

Task A: inline edit (about 1:00)

  1. Show cancel first. In the Explorer open src/flask/helpers.py. Find def get_debug_flag (Ctrl+F). Select the whole function, from def down to its return line.
  2. Press Ctrl+Alt+I (Mac: Cmd+Alt+I). A box opens at the top. Type add a detailed comment above every line and press Enter (a long answer, so there is time to stop it).
  3. As soon as the diff tab opens and starts filling, press Esc (or click the status-bar item "Anvil: generating..."). The diff closes. You see "inline edit stopped. No changes were made."
  4. Select the same function again, press Ctrl+Alt+I, paste the exact Task A instruction from Terminal 2, press Enter. Do not cut here.
  5. A diff tab opens. Left = the file now, right = the proposal, filling as the model writes. Above each change there is Accept hunk 1 and Reject. Click Accept above the docstring change, then Accept above the code change (one at a time, not "Accept all").
  6. Notification: "Anvil: applied 2 of 2 hunk(s) to src/flask/helpers.py." with an Undo button.
  7. In the VS Code terminal paste the Task A check. It must print False.
  8. Show undo: click Undo on the notification (or Ctrl+Shift+P → Anvil: Undo Last Applied Change). The function goes back to the original. That is all; move on to Task B.

Task B: agent mode (about 2:00)

  1. Click the anvil icon to open the Anvil panel. Click New at its top. Paste the exact Task B instruction into the box at the bottom and press Enter. Do not name any files.
  2. A "CONTEXT" card appears listing src/flask/cli.py, tests/test_cli.py, docs/cli.rst... with reasons and a token bar. Hover over it for 2 to 3 seconds so it is readable.
  3. Tool rows appear (retrieve_context, read_file...). You may cut this waiting time.
  4. A diff tab opens for src/flask/cli.py. Click Accept on each hunk (or "Accept all" at the top). The next file opens: tests/test_cli.py, then docs/cli.rst, then CHANGES.rst. Accept each one.
  5. If a "Run command" card appears in the panel (e.g. pytest), click Allow.
  6. The panel ends with "Done in ...s". Click Session at the top of the panel: the browser opens the TrueForge session. Click the "Agent steps · N tool calls" row to expand it so the tool calls are visible, scroll for 3 to 5 seconds, then go back to VS Code.
  7. In the VS Code terminal paste the Task B checks one by one: pytest says 60 passed or similar; flask --help lists config; the config command shows "SECRET_KEY": "***"; git diff --stat shows 3 or 4 files.

Task C: resilience (about 0:45)

  1. In the VS Code terminal paste the two Task C lines (they reset Flask and make the main model's key invalid; no real key is involved). It prints "BROKE anthropic". Then run git status: empty.
  2. Repeat Task A: open helpers.py, select get_debug_flag, Ctrl+Alt+I, paste the Task A instruction, Enter.
  3. While it works, click around (scroll the file, open the Explorer) to show the editor is not frozen. Notifications appear: "...claude-sonnet-5-5 failed (...401...). Retrying in 1s", then "...Falling back to anthropic-compat/claude-haiku-5-5 automatically." The diff then appears from the second model.
  4. Click Reject all at the top of the diff. In the terminal run git status. Empty output = workspace unchanged.
  5. Stop recording in OBS.
After the take: in Terminal 2 run ./anvil/scripts/demo-reset.sh (this restores the real key and resets Flask) before any retake.

Part 5. Trim, upload and send

  1. If it is over 4:00, trim only waiting time (Task B tool calls, the model thinking). Any simple editor works: Shotcut, Kdenlive, iMovie, or YouTube Studio's Editor after uploading. Never cut between pressing Enter on an instruction and the diff appearing.
  2. Upload to YouTube as Unlisted (not Private). Or Google Drive with sharing set to "Anyone with the link".
  3. Open the link in a private/incognito window to check it plays without logging in.

Part 6. If something goes wrong

What you seeDo this
Panel: "TrueForge is not reachable"Terminal 1 stopped, or Node is older than 22. Restart it, then Ctrl+Shift+P → "Anvil: Reconnect to TrueForge".
"ANTHROPIC_API_KEY is not set"Run the export line in Terminal 2, then demo-reset.sh again.
Task A or B fails with "401" when it should notThe key is still broken from a previous Task C. Run demo-reset.sh.
Ctrl+Alt+I does nothingSome code must be selected first, and the cursor must be in the editor (click in the file).
git status shows filesRun demo-reset.sh.
pytest "ImportError ... notset".venv/bin/pip install "pytest==8.4.2" in the Flask folder.
Task B takes a different path or edits other filesThat is fine as long as the checks pass. If a check fails, reset and retake.
Anything elseScreenshot it and send it to Shaunak.
